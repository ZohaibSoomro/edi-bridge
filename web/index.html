Key Platform & Parser Features

  • • Multi-Group Interchanges: Parses multiple GS/ST sets within a single payload and reports envelope/count validation errors.
  • • 997 Functional Acknowledgments: Generates per-group AK1–AK9 acknowledgments with unique control numbers and echoes inbound ISA15 (P or T).
  • • Batch File Processing: Upload multiple .edi, .x12, .txt, or .dat files at once to get combined JSON output and all generated 997s together.
  • • Inspector & Theme Controls: Switch between streamed and line-formatted EDI, copy or download JSON/997 files, inspect live latency and quota headers, and toggle Light or Dark mode.

How to Use the Playground

  1. Load or Paste X12 Data: Click a sample button (850, 810, or Multi-Group 850+214), paste raw X12 segments, or use Format EDI / Stream EDI for readability.
  2. Toggle 997 Generation: Keep Generate 997 Ack checked to synthesize a matching 997 using the incoming ISA15 indicator (P or T) and fresh control numbers.
  3. Run Single or Batch Upload: Click Parse & Validate → for the current editor payload, or click Upload File and select one or multiple EDI files to parse in parallel.
  4. Export Results: Use Copy JSON or Download JSON for normalized output, and click Download 997 (or Download 997 (N) for batches) when 997 output is generated.
